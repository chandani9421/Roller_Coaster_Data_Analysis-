# Roller_Coaster_Data_Analysis.

# 📌 Project Overview..............
This project focuses on analyzing roller coaster data to uncover trends, patterns, and insights related to coaster performance, popularity, and characteristics.

The goal is to perform Exploratory Data Analysis (EDA) and derive meaningful insights that can help understand what makes a roller coaster successful.

## 🎯 Objectives

* Analyze roller coaster features such as speed, height, and length
* Identify trends across different years
* Explore relationships between features
* Understand factors influencing coaster popularity

---

## 📊 Dataset Description

The dataset includes information such as:

* Roller Coaster Name
* Location
* Speed
* Height
* Length
* Year Opened
* Manufacturer
* Status

## 📈 Key Insights

* Roller coaster speed and height have increased over time
* Certain manufacturers dominate the industry
